# 去掉输入区底色

## Status

accepted（取代 ADR-0011 里「输入底色由 Highlighter 设置」这一条；reedline、补全菜单、历史与按键归属不变）

## 背景

输入块曾经把用户的话圈成一块：提示符上方一行浅灰边距、整行铺 `48;5;236` 底色、提交时逐行补满、下方再补一行边距。设计意图是「我说的」和「回答」一眼分开。

真用下来，这块颜色是噪声：终端里本来就有提示符和换行，色块额外占掉两行滚动区；粘贴多行、折行时还要维护每行右边是否补齐，代码不短。用户明确要求「输入区域不要做颜色区分」。

## 决定

- 输入行不再铺底色：删掉 `Highlighter`、提示符里的底色、上下边距与 `input_rows` 的行尾补齐。
- 提示符只剩 `> `（计划模式 `plan> `）。
- 重放旧提问按普通文本打印 `> 原文`，不再复刻色块。
- `nu-ansi-term` 随之移除，直接依赖 6 → 5。

## 考虑过的选项

- **保留底色、换成更接近背景的色号**：仍然是「区分」，与要求相反。否决。
- **只去掉上下边距、保留行底色**：色块没有边界，变成一条断头色带，比原来更难看。否决。
- **做成配置开关**：默认值已经是「不要」，多一个分支、多一份文档，按「无必要不加功能」否决。

## 影响

- 每轮少两行空白，滚动区更紧凑；粘贴多行不再需要逐行补底色。
- 输入行与普通输出之间只靠 `> ` 前缀区分。
- 直接依赖 6 → 5；`nu-ansi-term` 仍由 `reedline` 间接引入，二进制体积基本不变。
